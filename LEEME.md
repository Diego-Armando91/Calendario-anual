# Cuadrante 2027 — paquete para Claude Code

1. Descomprime esta carpeta en tu ordenador.
2. Ábrela en Claude Code.
3. Pega el texto de `PROMPT_INICIAL.md`.

Claude Code leerá `CLAUDE.md`, que tiene todo el contexto: tus reglas, los datos, el estado de las versiones y cómo se ejecuta.

- `data/`: tu Excel original, la leyenda de referencia y las propuestas v3 y v4.
- `scripts/`: el modelo y las herramientas. Los parámetros se cambian en `scripts/config.py`.
- `work/`: datos preparados y propuestas en CSV.
- `salidas/`: aquí aparecen los Excel, las imágenes y los calendarios.
